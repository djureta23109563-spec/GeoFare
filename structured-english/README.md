#GeoFare Structured English

This folder contains the Structured English documentation
for the GeoFare system.

##System

GeoFare: A Web-Based GPS Fare Computation and Route Monitoring
System for Tricycle Passengers Safety in Agoo, La Union.

##Processes

- 1.0 Manage Trip & Fare Computation
- 1.1 Capture Pickup Location
- 1.2 Capture Drop-off Location
- 1.3 Calculate Distance & Fare
- 2.0 Manage Route Monitoring
- 3.0 Manage Plate Identification
- 4.0 Manage Reports & LGU Dashboard
