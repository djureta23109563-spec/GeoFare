# 3.0 Manage Plate Identification

```text
BEGIN

    REQUEST Passenger to capture Tricycle_Plate_Image

    CAPTURE Plate_Image

    CALL OCR_PROCEDURE

    IF Plate_Number is successfully recognized THEN

        GET Plate_Number from OCR
        SAVE Plate_Number

    ELSE

        DISPLAY "Plate number could not be recognized"
        REQUEST Passenger to enter Plate_Number manually
        SAVE Manually_Entered_Plate_Number

    ENDIF

    LINK Plate_Number to Passenger's Trip_Record

    STORE Plate_Number in Trip_Logs

END
